# Vihar Interiors - Mobile Boilerplate

A mobile-first React + TypeScript boilerplate for interior designers and studios. Built with Vite, modern CSS, and PDF export capabilities.

## Features Included

- **Portfolio Webpage**: Client-facing showcase boilerplate with direct WhatsApp enquiry integration.
- **Quotation Generator**: Itemized room-by-room quote builder with instant client PDF download (`jsPDF`), email drafting (`mailto:`), and WhatsApp sharing.
- **Client Billing**: Milestone tracking and payment status ledger.
- **Expense Calculator**: Track material procurement, vendor bills, and contractor wages.
- **Mobile-First UX**: Responsive touch-friendly layout designed for phone viewports with bottom navigation.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Vanilla Mobile-First CSS (48px touch targets)
- **PDF Generation**: `jspdf`
- **Icons**: `lucide-react`

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
